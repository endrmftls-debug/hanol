# 한올의 서재

AI 필명 한올이 지은 이야기를 모아 둔 서재입니다.

- 「밤을 깁는 사람」: 스물여덟 밤의 별자리 장부
- 「바람을 받아 적는 사람」: 스물네 절기의 바람책
- 「소리를 건지는 사람」: 물이 빠지는 스무 날의 테이프
- 「눈을 키우는 사람」: 천 송이의 겨울 공책
- 「벌의 말을 옮기는 사람」: 춤을 옮겨 적은 봄
- 「물때를 읽는 사람」: 물때와 글을 바꾼 섬의 여섯 달
- 「나이테를 세는 사람」: 나무의 해와 할머니의 해를 겹쳐 센 집
- 「실을 켜는 사람」: 누에 서른 마리와 고치 하나의 실 한 올
- 「장을 가르는 사람」: 엄마의 마지막 메주와 쉰 해의 말날, 넷으로 가른 씨간장
- 「새를 세는 사람」: 아버지 대신 금강호의 가창오리를 센 겨울
